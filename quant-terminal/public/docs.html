🚀 Quickstart Guide

Get the entire AlphaForge quantitative stack running on your machine in 3 simple steps:

# 2. Start the Compiled Go Ultra-HFT Engine (Port 4050)

# 3. Start the Kronos AI Forecaster on NVIDIA RTX 3050 CUDA (Port 5050)

Once launched, visit http://localhost:4000/ to see live sub-microsecond telemetry streaming in the top navigation bar.

⚡ C++20 AVX2 SIMD Core (41.6 Nanoseconds)

Located in quant-terminal/cpp-engine/, this bare-metal binary uses Intel/AMD AVX2 SIMD intrinsic instructions (_mm256_loadu_pd, _mm256_fmadd_pd) to compute top-of-book microstructural features in parallel:

  • Order Book Imbalance (OBI): OBI = (V_bid - V_ask) / (V_bid + V_ask)
  • Merton Jump-Diffusion Simulation: Monte Carlo jump risk evaluation.
  • Throughput: 24,025,756 ticks/sec with mean latency of 41.6 nanoseconds.

⚡ Go Ultra-HFT Engine (0.24 Microseconds)

Located in quant-terminal/go-engine/, this standalone compiled daemon runs concurrent Goroutines consuming the live Binance WebSocket feed for PAXG/USDT (Spot Gold) and BTC/USDT:

  • Average Tick Latency: 0.24 µs to 0.57 µs (sub-microsecond).
  • HTTP Telemetry Endpoint: GET http://localhost:4050/health
  • Memory Footprint: Under 2.0 MB RAM across 8 Goroutines.
  • Uptime: Production daemon built for multi-day non-stop market ingest.

🧠 Kronos Deep Learning Foundation Model (AAAI 2026)

🛡️ Spread Armor & Stop-Loss Protocol

Trading with real money requires absolute mathematical risk boundaries. AlphaForge enforces three non-negotiable security layers:

  • Micro-Capital Safety Cap: In realTradingService.js, maximum allocated trade size is hard-capped at $20.00.
  • 2% Max Loss Constraint: If a position loses more than 2% ($0.40 on a $20 trade), the order is immediately liquidated.
  • Spread Armor Gate: If the broker's bid-ask spread exceeds 0.05%, trading is frozen to prevent predatory slippage.

⚡ Exchange Circuit Breakers

AlphaForge features built-in emergency circuit breakers designed to protect house balance:

Daily Drawdown Lock: If net daily loss reaches $2.00 (10% of a $20 balance), all trading is automatically suspended for 24 hours. No new orders can be submitted until the daily cooldown expires.
