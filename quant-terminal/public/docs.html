⚡ Dual Computational HFT Engines

1. C++20 AVX2 SIMD Core

Located in quant-terminal/cpp-engine/, this bare-metal binary uses Intel/AMD AVX2 SIMD intrinsic instructions to compute top-of-book microstructural features in parallel:

  • Order Book Imbalance (OBI): OBI = (V_bid - V_ask) / (V_bid + V_ask)
  • Merton Jump-Diffusion Simulation: Monte Carlo jump risk evaluation.
  • Throughput: 24,025,756 ticks/sec with mean latency of 41.6 nanoseconds.

2. Go Ultra-HFT Engine (Port 4050)

Located in quant-terminal/go-engine/, this standalone compiled daemon runs concurrent Goroutines consuming the live Binance WebSocket feed for PAXG/USDT (Spot Gold) and BTC/USDT:

  • Average Tick Latency: 0.24 µs to 0.57 µs.
  • HTTP Telemetry Endpoint: GET http://localhost:4050/health
  • Memory Footprint: Under 2.0 MB RAM across 8 Goroutines.

🛡️ Bank-Grade Security & Capital Guard

Trading with real money requires absolute mathematical risk boundaries. AlphaForge enforces three non-negotiable security layers:

MANDATORY API SECURITY RULE: When creating API keys on Binance or Capital.com, check "Enable Reading" and "Enable Spot Trading" ONLY. LEAVE "ENABLE WITHDRAWALS" PERMANENTLY UNCHECKED.
  • Micro-Capital Safety Cap: In realTradingService.js, maximum allocated trade size is hard-capped at $20.00.
  • 2% Max Loss Constraint: If a position loses more than 2% ($0.40 on a $20 trade), the order is immediately liquidated.
  • Spread Armor Gate: If the broker's bid-ask spread exceeds 0.05%, trading is frozen to prevent predatory slippage.
  • Exchange-Side OCO Protection: Stop-loss orders are posted directly to the exchange matching engine, protecting capital even during internet failure.
