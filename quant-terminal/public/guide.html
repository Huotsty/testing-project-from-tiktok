3 Creating Your Secure API Key (The Golden Security Rule)
🚨 CRITICAL SECURITY DIRECTIVE:
In your Binance API Key settings, LEAVE "ENABLE WITHDRAWALS" UNCHECKED / DISABLED!
By doing this, it is physically impossible for anyone (including AlphaForge or any external hacker) to withdraw your money. The bot can only place spot trades with your stop-loss inside your own account.
  1. Log in to Binance ➔ Tap your Profile Icon ➔ Select API Management.
  2. Click Create API ➔ Choose System generated API key.
  3. Name it: AlphaForge-Bot.
  4. Complete your 2-Factor Authentication (Google Auth or SMS).
  5. On the API permissions list:
    • ✅ Check: Enable Reading
    • ✅ Check: Enable Spot & Margin Trading
    • ❌ LEAVE UNCHECKED: Enable Withdrawals
  6. Copy your API Key and Secret Key.
